# Jiaqi Wu · Personal Website

Static GitHub Pages site for [wujiaqi2005love-byte](https://github.com/wujiaqi2005love-byte).

## Publish

This repository is named `Jiaqi-WU.github.io`, so the site can be served at:
`https://wujiaqi2005love-byte.github.io/Jiaqi-WU.github.io/` (project site) or through a configured custom domain.

To publish from GitHub, open **Settings → Pages**, select the branch containing this site and `/ (root)` as the source, then save. GitHub Pages will publish the static `index.html` and its CSS/JS files.

## Customize

- Edit the content in `index.html`.
- Adjust colors and layout in `style.css`.
- The language switch and current-year footer are in `script.js`.
- Replace links and project descriptions with your own details as you add work.
